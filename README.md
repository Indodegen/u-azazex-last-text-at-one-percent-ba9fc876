# Last Text at One Percent

One last text from a dying phone at 1% battery — in the phone's own voice.

Bounty: https://make.fun/bounty/u-azazex-last-text-at-one-percent-ba9fc876

The entry is a single text message under 200 characters, stored in `entry.txt`.

## Run

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
